## 기능별 변경 요약

### 1. My Lap 섹터 표시 유지 + S3 역산
문제: (1) S3 실제 기록이 절대 안 뜸(`•••`/대시), (2) 새 랩 시작 즉시 S1·S2가 사라짐.
근본 원인: `deriveMyLap`은 순수 함수라 프레임 간 상태를 못 가짐 → 완료 섹터를 기억하는 hook 필요.

```
[라이브 게이팅]  currentSector 리셋 → 즉시 대시
[유지 방식]      완료 트리오 붙듦 → 다음 랩 S1 완주 시에만 리셋
```

- 신규 `useSectorDisplay.ts`: 순수 reducer `advanceSectorDisplay` + `usePlayerSectorDisplay` hook
- S3 = 롤오버 시 `lastLapTime − s1 − s2` (accumulator `bestS3`와 동일 기법, 완료 랩 실측)
- `myLap.ts`: `SectorDisplay` 인자 도입, currentSector 게이팅 제거, `s3Color` 추가

### 2. 리더보드 타이어 마모 4사분면 컬럼
`damage` 컬럼의 2×2 그리드 패턴을 본떠 `tireWear` `[FL,FR,RL,RR]`을 물리적 배치로 표시.

```
FL%  FR%   ← 앞(위)
RL%  RR%   ← 뒤(아래)
```

- `columns.ts`: `tyreWear` 키(width 140·헤더 "Tyre Wear"·칩 "Wear"·기본 숨김)
- `leaderboardRows.ts`: `tyreWearTone`(60/35 임계) + `tyreWearCell` + `LeaderRow` 8필드
- 기본 숨김 → Display Settings 'Wear' 칩으로 토글

### 3. Pit Exit unavailable 사유 콘솔 로깅
`Pit-loss data unavailable` 표시 시 null 반환 3사유를 진단. 매 프레임 도배 방지 위해
사유가 바뀔 때만 `console.warn`(useMemo 안정화 + useEffect).

## Edge Cases / degrade
- ✅ 섹터 S3 무효(아웃랩 `lastLapTime≤0`) → 트리오 덮어쓰지 않음
- ✅ 리플레이 rewind(랩 되감김) → 섹터 표시 상태 리셋
- ✅ 타이어 마모 배열 결측(길이<4) → 네 칸 대시
- ✅ 타이어 `[0,0,0,0]`(프레시) → 0% 표시(결측 아님)
- ✅ 신규 컬럼 키 → prefs/토글칩/리사이즈 자동 처리(Record 완전성 TS 강제)

## 핵심 설계 결정
| 결정 | 이유 |
|---|---|
| 섹터 상태를 hook으로 유지 | 순수 유도로는 프레임 간 유지 불가 |
| 전이 로직을 순수 reducer로 분리 | 상태 머신 단위 테스트 가능 |
| S3 역산 허용(MyLap) | 완료 랩 실측치 재사용 — accumulator bestS3와 동일, 신규 fabrication 아님 |
| 타이어 마모 컬럼 기본 숨김 | damage/sector와 동일한 opt-in 정책 |

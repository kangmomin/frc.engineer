# race-analysis 사고 과실 판정 — 게임 판정 병기 + FIA 2026 원문 기준 채택

- **날짜**: 2026-08-15
- **이슈**: race-analysis 리포트의 사고 분석이 게임 페널티 판정에만 의존했다. 사용자가 "게임
  판정 말고 공식 규정집 기반으로 누구 잘못인지 판단"을 요청 — 근거 규정의 범위(어느 문서·
  어느 버전), 판정 척도, 게임 판정과의 관계, 텔레메트리 기하 임계값의 신뢰성에 판단이 필요했다.
- **결정**:
  1. **근거 문서 3종을 FIA 원문 PDF로 고정**: 2026 F1 Driving Standards Guidelines v01
     (2026-02-26) + 2026 F1 Penalty Guidelines v01 + ISC Appendix L 2026(6/23 발행) Ch.IV.
     Sporting Regulations 전문은 가져오지 않음(필요 B-조항은 DSG가 원문 인용). 문서에 없는
     관습 지식(예: "랩1 관용" 일반론)으로 채우지 않는다.
  2. **LLM 위키 형식** = 안정 규칙 ID(`DSG-A`, `APXL-2b`…) + 영문 원문 인용 + 한국어 요약 +
     텔레메트리 매핑 + 판정 절차. 위치: `.claude/skills/race-analysis/references/fia-driving-standards.md`.
  3. **게임 판정과 병기**: FIA 판정은 게임 판정(events 페널티 매핑)을 근거로 쓰지 않고 독립
     산출, 리포트에 나란히 표기. 게임 페널티 미발부 시 "게임 판정 없음" 고정 표기.
  4. **판정 척도는 스튜어드 실제 용어**: wholly / predominantly to blame / racing incident.
     데이터 부족은 racing incident로 뭉개지 않고 "판정 불가(확신도 낮음)".
  5. **홀리스틱 필수 통과**: DSG 원문이 위치 스냅샷 단독 판정을 금지하므로(DSG-CAV·NOTES)
     위치 기준(DSG-A/B) 충족 여부와 무관하게 CAV 4항·NOTES 10항 점검 후 결론.
  6. **기하 임계값 정책**: Belgium 2026-08-13 클립 3건으로 캘리브레이션 —
     검증 확정(지면 평면 x–z, yaw 헤딩 관례, speedKmh=|v|·3.6, 기준점=차량 중심, 차폭 2.0m,
     입력 범위, 슬립각 신호) / [추정] 유지(차 길이 5.6m, 미러 라인 −0.8m, brake 0.2 — 전후
     접촉 사례 부재로 미검증). minDistM은 중심 거리라 접촉 마커로 쓰지 않고 COLL 시각을 쓴다.
- **결정자**: 사용자(요구·접근 확인 "ㄱㄱ") + 에이전트(문서 선정·형식·임계값 정책)
- **근거**: DSG가 스튜어드의 실제 판정 기준(미러 라인·액슬 기준·회피 책임 방향)을 원문으로
  제공하는 유일한 공개 문서이고, 2026 시즌(F1 26 게임 대응) 버전이 존재. 게임 판정은 재현
  불가한 블랙박스라 독립 판정+병기가 신뢰 규율(스킬 원칙)에 부합.
- **기각된 대안**: Sporting Regulations 전문 위키화(중복·비대), 관습 지식 보강(원문 충실성
  훼손), 게임 판정을 FIA 판정의 prior로 사용(독립성 훼손). 시험 적용에서 코너명 단정
  표기(lapDistance 대응 부재로 [추정] 표기만 허용).
- **수정 내역**: `.claude/skills/race-analysis/references/fia-driving-standards.md`(신규),
  `SKILL.md` Step 3-8 과실 판정 포인터 추가. 캘리브레이션 반영(위키 §4.0·§5).
- **재발 시 대응**: "게임 판정이 있는데 왜 따로 판정하나" / "미러 라인 몇 m가 근거냐" /
  "코너명 왜 안 쓰나" 재제기 시 본 문서와 위키 §4.0·§5 인용으로 종결. 임계값 갱신은 전후
  접촉 클립 확보 시 캘리브레이션 재실행으로만.

## 추가 결정 — 멀티계정 세션 분석 규칙 (2026-08-15, UK 세션 적용)

같은 세션을 5계정이 업로드한 UK(실버스톤) 세션에 스킬을 적용하며 내린 방법론 결정:

1. **이벤트 실건수는 타임스탬프 클러스터링으로 복원** — (드라이버명 정규화·메시지 코어·ts±15s).
   최초 가정 "원시 ÷ 계정수"는 계정별 로그 커버리지 불균일로 반증되어 기각(361 원시 → 79 클러스터).
2. **이벤트 lap 태그는 업로더의 현재 랩** — 본인 페널티 랩은 본인 업로드로만 확정, 비업로더는 `?` 근사.
3. **클립 국면 병합은 t0(세션 게임시간) 5초 그룹핑** — 양측 시점 국면은 상호 dLong/dLat 부호 반전
   일치로 교차 검증(0.1~0.5m 이내 통과). 다중 차량 혼전(랩1 T1 10대)은 단일 시점 클립으로 과실
   배분하지 않고 서술+판정 불가 처리(DSG-D 랩1 관용 인용).
4. **`pit_lane_time_ms` 의미 확정** — 레인 1회 통과 시간(마지막 계측, uint16). 스톱 수와 무관함을
   1스톱 3계정(33.2~33.5s)과 2스톱 1계정(33.0s) 대조로 확인. "2스톱인데 33s" 재제기 시 본 항목 인용.
- **결정자**: 에이전트 (advisor 검토 반영 — ÷5 산술 기각은 advisor 지적)

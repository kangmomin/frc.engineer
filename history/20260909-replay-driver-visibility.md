# 사고 리플레이의 드라이버 색상과 표시 범위

- **날짜**: 2026-09-09
- **이슈**: 사용자가 드라이버별 차량·주행 라인 색상과 개별 숨김 기능을 요청했다. 팀 색상은 팀 동료를 구분하지 못한다.
- **결정**: 기록된 차량 `idx`에 고정 색상을 부여하고 차량·주행 라인·전체 트랙 마커·목록에 공유한다. 표시 옵션은 `차량 + 라인`, `차량만`, `숨김`이며 숨김은 텔레메트리 행에도 적용한다. 선택은 사고 클립별 화면 상태로 두고 새 클립에서는 모두 표시한다.
- **결정자**: 에이전트 — 사용자 기능 요청을 바탕으로 구현하고 독립 리뷰에서 검증했다.
- **근거**: 표시를 바꿔도 차량 색상과 원본 데이터 연결이 유지되어야 한다. 색상·표시·freshness는 `idx`를 사용하지만 `frame.cars`는 원본 참가자 배열 위치로 읽는다. 숨김은 렌더링에만 적용해 지도 범위·재생 시점·카메라를 유지한다.
- **기각된 대안**: 참가자 배열을 먼저 필터링하면 희소 차량 번호와 프레임 튜플 위치가 어긋날 수 있다. 필터 결과 순서로 색상을 배정하면 숨김·복원 시 색상이 바뀐다.
- **수정 내역**: `IncidentReplay.tsx`, `ReplayDriverControls.tsx`, `analysisDriverDisplay.ts`, 관련 스타일 및 SSR·브라우저 회귀 검증.
- **재발 시 대응**: 차량 번호와 프레임 배열 위치를 혼동하거나 필터로 카메라가 바뀌는 제안에는 이 결정을 적용한다.

# 사고 리플레이: 재생 컨트롤을 지도 바로 아래로 옮기고 전체 트랙 미니맵 제거

- **날짜**: 2026-09-10
- **이슈**: 사고 리플레이의 지도(플레이어)와 재생 컨트롤 사이에 전체 트랙 미니맵(`TrackOverview`,
  "전체 트랙 · 현재 프레임")과 트랙 자료 안내 문구가 끼어 있어 지도와 컨트롤이 떨어져 있었다.
  (출처: 사용자 요청 "VIDEO CONTROL 영역이 PLAYER 영역 바로 아래 위치하게 해 줘. 전체 트랙 표시는 없애도 돼")
- **결정**:
  1. 재생 컨트롤(버튼·타임라인·상태 문구)을 지도 바로 다음에 둔다. 트랙 경계·코너 번호·차체 크기
     안내 문구는 컨트롤 아래, 텔레메트리 위로 옮긴다.
  2. 전체 트랙 미니맵을 제거한다. 지도 툴바의 "전체 트랙" 맞춤 버튼은 표시가 아닌 카메라 조작이므로 유지한다.
  3. 브라우저 회귀 테스트가 미니맵(`data-overview-car`)을 참조 트랙 로드 신호로 쓰던 검사는 메인 지도의
     `svg[aria-label^="Reference track"]`로 바꾼다. 미니맵 고유 검사(프레임 동기화, 확대 독립성, 모바일 폭)는
     삭제하고, 트랙 밖 차량 이동 검사는 메인 지도 차량으로 유지한다. 도로 면(`data-road-surface`) 기대 개수는
     메인 지도와 미니맵 두 벌(`* 2`)에서 메인 지도 한 벌로 줄인다. 컨트롤이 지도 바로 다음에 오는지 검사를 추가한다.
- **결정자**: 사용자(미니맵 제거, 컨트롤 위치) / 에이전트("전체 트랙 표시"를 미니맵으로 해석해 맞춤 버튼 유지, 테스트 신호 교체)
- **근거**: 미니맵의 전체 트랙 확인은 메인 지도의 "전체 트랙" 맞춤으로 대신할 수 있다. 컨트롤은 기존
  `replayGrid` 첫 칸에 그대로 두고 앞의 요소만 걷어내 코드 이동을 최소화했다.
- **기각된 대안**:
  - 컨트롤을 지도 테두리에 붙인 플레이어 바로 재디자인 — 요청 범위는 위치 변경이다.
  - 미니맵을 컨트롤 아래로 옮겨 유지 — 사용자가 제거해도 된다고 명시했다.
